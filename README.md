# Workout Expert System 💪

AI-Powered Fitness Recommendation Engine built with Python, Experta (Expert System Framework), and Flask.

## How to Run This Project

Follow these simple steps to run the project on your machine:

### 1. Prerequisites
Make sure you have **Python 3.10 or newer** installed on your computer. You can download it from [python.org](https://www.python.org/).

### 2. Install Dependencies
Open your terminal or command prompt inside the project folder (`systemxprt`) and run the following command to install the required libraries:

```bash
pip install -r requirements.txt
```

### 3. Run the Web Application
Start the Flask server by running:

```bash
python ui/app.py
```

After running the command, open your web browser and go to:
**http://127.0.0.1:5000**

---

### Command Line Interface (CLI) Mode
If you prefer to use the tool in the terminal without the web interface, you can run:

```bash
python main.py
```

### Running Tests
To verify that the engine is working correctly, you can run the built-in test scenarios:

```bash
python main.py --test all
```
